# タスク（50分）

## Step1 実装対象を決める（5分）
- 実装する機能を1〜2個に絞る
- 推奨: 予約登録 + 予約確認

## Step2 実装方針を決める（5分）
- HTML/CSS/JavaScript の単一アプリ か 簡単な Python アプリに絞る
- 今回作らないものを先に決める

## Step3 ルールを決める（5分）
- コーディングルールを3〜4個に絞る
- 例: 名前が分かりやすい / 関数を長くしない / 入力チェックを入れる

## Step4 初回実装を作る（20分）
- 資料をAIに渡して実装を依頼する
- まずは作成ファイル一覧を出させる
- 複雑なら簡素化を依頼する

## Step5 動作確認して直す（10分）
- 画面が開くか
- 主要操作ができるか
- 入力チェックがあるか
- 不具合をAIに伝えて修正する

## Step6 ミニレビューする（5分）
- 命名 / 入力チェック / 複雑すぎないか の3点だけ確認する
- 次の演習でテストしたい点を3つメモする
