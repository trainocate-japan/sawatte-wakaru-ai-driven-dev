# 提出ガイド

## 保存先

各チームは `submissions/<team-name>/` を作成して保存します。

## 命名例

- `submissions/team-a/01-requirements.md`
- `submissions/team-a/02-specification.md`
- `submissions/team-a/03-design.md`
- `submissions/team-a/04-implementation.md`
- `submissions/team-a/05-testing.md`
- `submissions/team-a/06-documentation.md`

## 提出時に確認すること

- テンプレートの空欄が残りすぎていないか
- AIが書いただけの文章になっていないか
- 次の演習で使う情報が入っているか
