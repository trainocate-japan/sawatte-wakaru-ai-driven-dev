# 進め方ガイド

## 基本の進め方

各演習は次の順で進めます。

1. `01-overview.md` を読む
2. `02-tasks.md` に沿って進める
3. 必要なら `03-input.md` を埋める
4. AIを使うときは `04-prompts.md` を参考にする
5. `06-template.md` に成果をまとめる
6. `07-rubric.md` で見直す

## AI活用の基本ルール

- AIの出力をそのまま提出しない
- 分からない内容は採用しない
- 曖昧な点は「未確定事項」に残す
- 長い依頼より、小さく分けて頼む

## 迷ったときの判断基準

- 次の演習に進みやすいか
- 初学者が説明できる内容か
- 50分以内で扱える範囲か
